# 🚀 Day 05 — Form Validation

Part of my 21 Days JavaScript Challenge.

## 📌 Overview
A simple login form with real-time validation.

## 🎯 Goal
Validate user inputs and show errors.

## 🧩 Features
- Required field validation  
- Email format check  
- Password length validation  
- Error messages display  

## 🧠 Flow
1. Get input values  
2. Check empty fields  
3. Validate email format  
4. Validate password length  
5. Show errors or success  

## 🖥 Tech
HTML | CSS | JavaScript  

## 💡 Learning
Form validation + user input handling
